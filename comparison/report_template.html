对比口径与数据来源

v3 在指令实际发射时原子分配输入 / 输出空间，依赖 full 和复用 empty 共享 barrier ID 池，完成时申请并发布。v3.1 在提交前顺序申请 buffer 与 barrier，后续 API 阻塞时保留已分配资源；buffer ID 有独立 freelist，数据依赖与共享输入的消费完成通知使用 barrier 池。

因此“相同容量”只代表 buffer 数量和 barrier 数量相同，barrier 承担的事件种类及分配时点仍然不同。这里展示的是各版本现有固定调度策略的轨迹，不是所有可能调度中的最优容量证明。

平均占用 = 所有 buffer 生命周期时长之和 / 全程时间；输出预占用均值 = 每个输出 buffer 从分配到生产者开始的时间均值（不含源输入）。物理 buffer 不重复计算共享消费者的输入。源输入计入池，最终输出在完成时由外部立即接收。
