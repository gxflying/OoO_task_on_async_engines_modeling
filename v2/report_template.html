模型边界与验证

  • 所有依赖都作为真实数据输入；双输入指令保留两块上游 buffer。一次执行另分配一块输出，禁止输入输出同址。
  • 分配发生在发射时，所需新 buffer 一次性分配成功才发射；不会半分配后等待。队列条目不预占数据 buffer。
  • 首级 RDMA 从外部获得的数据占一块池内输入 buffer，执行完成即释放；末级 fa2 输出在执行结束时由零延迟外部 sink 接收。
  • 输出从生产者开始执行就占用，直到全部直接消费者执行结束才释放；尚未发射的消费者同样阻止提前回收。
  • buffer 槽位用 slot + generation 标识，复用时递增代数，旧 handle 不能访问新内容。
  • 一个全局前端按程序序入队，队列满反压。RDMA/WDMA/Tensor/Vector 各一个，固定按此顺序仲裁同时发生的 buffer 分配；队列内选择最老的就绪且资源足够的指令。
  • 同一时间边界先完成并释放，再入队、分配和发射；结果就绪与最后消费者释放是两个不同事件。
  • 未建模额外 memcpy、带宽/bank 冲突或真实矩阵计算。每块容量记为 B，总数据容量为 buffer 数量 × B；不指定未经提供的字节数。
